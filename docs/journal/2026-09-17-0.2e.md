# RainWatch development journal — Version 0.2e

Version 0.2e adds short historical NOAA/NESDIS satellite animation without claiming cloud-motion vectors, synchronizing it to radar, or changing the current-image behavior of Radar + Satellite.

## Official archive behavior

RainWatch uses NOAA/NESDIS's `MERGEDGC_Last_24hr` ImageServer. Its live service description identifies it as a time-enabled, rolling 24-hour merged GOES-East/GOES-West GeoColor archive with a new image every 10 or 15 minutes depending on scan mode. The service exposes `start_time` and `end_time` date fields, supports ordering and pagination, permits LockRaster mosaics, and allows one raster per exported mosaic.

The provider queries 30 newest records, validates the returned object IDs, names, and end times, sorts actual records chronologically, then keeps at most the latest three hours and 20 frames. On the implementation date the real cadence was ten minutes and the default window contained 19 frames. RainWatch does not create timestamps for missing records.

The separate `Most_Recent_MERGEDGC` provider remains the current-image fallback and continues to serve Radar + Satellite mode.

## Loading and cache policy

- Archive metadata loads when Satellite mode is first selected.
- The newest archive frame is selected by default.
- Only the selected frame is exported; the other 18 images are not prefetched on open.
- Previous, Next, slider, and playback selections lazily request their frame.
- Exports are clipped to the visible map bounds, Web Mercator, and a maximum of 1600 × 1200 pixels at up to 1.5× density.
- The service worker keeps up to 40 successful archive export URLs for 24 hours with CacheFirst reuse. Other NOAA requests remain network-only.
- Opacity changes update MapLibre paint only and do not alter the image URL.
- A pan or resize creates one replacement request for the selected frame after movement settles.

An archive metadata failure leaves the current NOAA image visible when available. If a previously loaded archive exists, a failed refresh preserves it. An individual image error leaves the other map layers available and marks that frame so active playback can skip it rather than repeatedly freezing there.

## Measured bandwidth

Measurements used the default whole-USA desktop map viewport, a 1215 × 446 PNG export, and the 19 real records returned during verification.

| Item | Measured transfer |
| --- | ---: |
| Archive metadata for 30 records | 4,457 bytes (4.35 KiB) |
| Initially selected/latest frame | 1,220,441 bytes (1.16 MiB) |
| Initial Satellite open, excluding basemap/current metadata | about 1.17 MiB |
| All 19 unique animation images | 25,220,500 bytes (24.05 MiB) |
| All images plus archive metadata | 25,224,957 bytes (24.06 MiB) |
| Average unique frame | 1,327,395 bytes (1.27 MiB) |
| Smallest / largest measured frame | 1,220,441 / 1,367,006 bytes |
| One representative pan for the selected frame | 1,361,804 bytes (1.30 MiB) |

The full-window figure is incurred only after the user views or plays every unique frame. Looping back to a previously loaded frame/viewport reuses the same URL and the production PWA cache rather than intentionally downloading another copy. Real totals vary with viewport, pixel ratio, content compressibility, cadence, and provider availability.

## User interface and semantics

Satellite mode now has an independent chronological slider, Play/Pause, Previous, Next, frame position, absolute timestamp, relative age, and opacity. Home and End keyboard keys select the oldest and newest available records through the native range control. Playback advances every 1.5 seconds and loops newest to oldest.

Radar playback state remains independent. Radar + Satellite deliberately shows the latest satellite image with the existing radar timeline; it does not suggest that the two products share observation times.

## Scope intentionally not added

- no cloud-motion vectors or optical flow
- no rain/cloud ETA
- no radar/satellite synchronized playback
- no precipitation forecast
- no backend, account, database, or API key
