# RainWatch development journal — Version 0.2g

Version 0.2g is a reliability and interface-cleanup milestone. It adds bounded recovery for the existing NOAA Satellite paths and pauses the two Cloud Cover experiments without deleting their code. It does not add motion analysis, ETA, extrapolation, forecasts, providers, or geographies.

## Satellite recovery policy

Latest and historical NOAA metadata now share one request wrapper with a 12-second timeout per attempt. Transient network failures, timeouts, HTTP 408/429/5xx responses, and retryable ArcGIS provider failures receive at most two retries: after 750 milliseconds and 1.5 seconds. Other 4xx responses and explicitly permanent provider errors stop immediately. Cancellation also stops immediately.

Satellite image rendering receives one retry after one second. A historical frame is marked failed only after that retry is exhausted, so playback skips it instead of repeatedly requesting it on every loop. The retry counts are configurable constants and no path retries indefinitely.

Failures are categorized as network, timeout, HTTP, provider/data unavailable, or image rendering. The map shows short messages such as `NOAA Satellite service is temporarily unavailable`; detailed category and attempt information remains in browser warnings for diagnosis.

## Last-valid behavior

A failed or empty metadata refresh no longer replaces existing latest imagery or historical metadata. RainWatch keeps that valid state, marks it **Last available**, and continues to show the actual observation age. A later successful Refresh clears the label. The first-ever request can still report unavailable because there is no safe image to preserve.

Radar requests and rendering remain independent. Radar + Satellite therefore keeps Radar visible when Satellite is unavailable, and Satellite remains visible when matched Radar is unavailable. The latest-image provider remains the fallback when archive metadata fails.

## Paused Cloud Cover experiments

Cloud Cover and Smooth Cloud · Lab remain visible in the five-button selector but use native disabled button semantics, muted styling, and the title `Cloud Cover experiments paused`. They cannot change the current mode. Radar, Satellite, and Radar + Satellite remain enabled.

The app stores only enabled selections. Any older stored value for either paused mode, an invalid value, or no value falls back to Radar. The Open-Meteo providers, hooks, layer code, legends, tests, documentation, screenshots, and experiment page remain intact for later review.
