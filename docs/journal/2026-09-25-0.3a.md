# RainWatch development journal — Version 0.3a

Version 0.3a is the Radar First + Rain Nearby milestone. It simplifies the normal interface around Radar and answers whether meaningful precipitation is over an approximate target, where the nearest detected precipitation is, and whether recent nearest-distance history shows a conservative directional trend. It does not calculate rain or clearing ETA, extrapolate Radar, or add a forecast.

## Radar-first interface

`src/config/features.ts` is the single feature-visibility source. Satellite, sampled Cloud Cover, Smooth Cloud · Lab, Radar + Satellite, and the Wind card are hidden. Their providers, hooks, components, services, tests, and prior documentation remain in the repository. Radar is the only visible selector option, and any stored hidden or invalid mode normalizes to Radar.

The existing location action is now labelled **My Area**. It requests the browser's approximate position or returns to it at a useful Radar zoom. Without location permission, Rain Nearby explicitly targets the map center.

## Rain Nearby technique

RainViewer's documented coordinate-tile form provides a 512 × 512 image centered on the target at fixed zoom 6. This makes analysis independent of the visible MapLibre zoom. Coordinates are grouped into approximately 0.02-degree buckets before requesting data, so tiny map movements do not refetch. The request URL is rounded to two decimal places.

Each analysis loads the five newest unsmoothed (`0_0`) Universal Blue Radar frames and one current coverage mask. Pixel colors are matched exactly against RainViewer's documented Universal Blue table. Returns below 20 dBZ are ignored; 20–34 dBZ is labelled weak, 35–44 moderate, and 45 dBZ or higher strong. These are reflectivity categories, not rainfall rates.

The target checks a two-mile radius to avoid single-pixel fragility. If that area is clear, the same image is scanned outward to a maximum 100-mile radius. Approximate distance uses Web Mercator ground resolution at the target latitude; direction uses the pixel offset bearing rounded to eight compass points. The scan never expands to a national area.

The coverage mask is checked at the target before any no-rain claim. An uncovered target reports **Radar coverage unavailable here**. The 100-mile empty result is worded as no rain detected in available Radar coverage because coverage can vary near the search boundary.

## Trend confidence

The five recent frames are chronological. A trend requires at least three usable distances, a net change of at least five miles, and at least 75 percent of step-to-step changes agreeing by one mile or more. A consistent decrease becomes **Appears to be approaching**; a consistent increase becomes **Appears to be moving away**. Other usable sequences say **Trend unclear**, and insufficient history says **Movement unavailable**. Echo growth and decay remain a known limitation, so no ETA is inferred.

## Failure isolation and freshness

Radar Nearby has a 12-second bounded timeout. Coverage, CORS, decoding, or latest-frame failures produce a compact unavailable state while the MapLibre Radar remains usable. Missing older frames reduce trend confidence rather than failing the latest result. Analysis reruns when Radar metadata refresh succeeds, the latest frame changes, the target crosses a meaningful bucket, or Refresh Radar is used.

RainViewer analysis URLs remain under the existing Workbox `NetworkOnly` rule and are not persisted as weather analysis. Immutable frame images may still use normal browser HTTP caching. The display's 256-pixel smoothed XYZ tiles cannot be directly reused because analysis deliberately uses one fixed 512-pixel, unsmoothed, coordinate-centered tile.

## Playback polish

Radar playback now holds the newest frame for two normal frame intervals before looping. A visible **Latest** button returns directly to the newest frame and stops playback. Previous, Next, Play/Pause, opacity, timestamps, and manual freshness behavior remain intact.

## Known limitations

- Nearest-distance history describes echo behavior, not proven storm motion; precipitation can form, dissipate, split, or merge.
- Universal Blue pixels are interpreted as Radar reflectivity categories, not rainfall rate.
- Coverage is confirmed at the target; the outer part of a 100-mile search can contain partial coverage gaps.
- Fixed zoom 6 and a local ground-resolution approximation intentionally trade fine precision for a bounded, lightweight scan.
- Exact GPS, accuracy circles, saved addresses, notifications, forecasts, storm tracking, optical flow, and ETA remain out of scope.
