Architecture snapshot

  • UI: React state and components
  • Map: MapLibre GL JS 6.9.0
  • Basemap: configurable OpenFreeMap development style
  • Radar: RainViewer historical frames plus fixed-zoom, coordinate-centered Universal Blue analysis behind service utilities
  • Satellite: observed NOAA/NESDIS merged GOES GeoColor latest image plus rolling archive
  • Cloud Cover: Open-Meteo Best Match model percentages behind a provider interface
  • Smooth Cloud lab: Open-Meteo Weather Map Layer 0.1.1, NOAA HRRR CONUS, and partial .om range reads
  • Wind: Open-Meteo Best Match current 10 m speed, meteorological direction, and gusts
  • Location: browser Geolocation API with explicit user action
  • PWA: Vite PWA plugin and Workbox app-shell precache
  • Deployment: static GitHub Pages site at /rainwatch/
