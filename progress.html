Architecture snapshot

  • UI: React state and components
  • Map: MapLibre GL JS 6.9.0
  • Basemap: configurable OpenFreeMap development style
  • Radar: RainViewer historical frames behind a provider interface
  • Location: browser Geolocation API with explicit user action
  • Deployment shape: static client-side files
